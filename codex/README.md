# Codex Home Assistant App

Run the official OpenAI Codex CLI in an isolated Debian 13 development
environment, directly from a Web terminal in Home Assistant Ingress.

The App includes Git, GitHub CLI, OpenSSH client/server, Node.js, Python,
common development tools, persistent Codex configuration, and a persistent
`/work` directory.

See [DOCS.md](DOCS.md) for installation, authentication, GitHub, SSH, package,
storage, and security instructions.
