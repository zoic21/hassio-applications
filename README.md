# Home Assistant Apps

Home Assistant Apps maintained by [zoic21](https://github.com/zoic21).

## Installation

Add this repository in **Settings → Apps → App store → Repositories**:

```text
https://github.com/zoic21/hassio-applications
```

## Available Apps

### Codex

Run OpenAI Codex CLI in an isolated Debian 13 development environment through
a Web terminal integrated with Home Assistant Ingress.

See [Codex documentation](codex/DOCS.md) for configuration and usage.
